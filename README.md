# Conway's Game of Life

An interactive implementation of John Conway’s cellular automaton simulation built in Python using Pygame.

## How It Works
Conway's Game of Life is a zero-player game whose evolution is determined entirely by its initial state. The simulation updates across generations based on simple rules governing cell survival, birth, and death on a 2D grid.

## Controls & Usage
- **Mouse Clicks:** Click on grid cells at game start-up or during pause mode to toggle them between alive and dead.
- **Enter Key:** Start the simulation, or pause it to modify the grid with additional mouse clicks before resuming.

## Requirements
- Python 3.x
- `pygame` library
